# 雨间 · 我该去哪 | Rainward · Where Should I Go

![雨间 · 我该去哪](rain-guide/mod/thumbnail.png)

《雨世界》交互地图与无剧透路线提示。项目保留原地图的地形、房间和连接交互，并以故事线索帮助玩家判断下一步方向，同时尽量保留探索体验。

**[打开网页](https://littlhmw.github.io/rainward/)** · **[GitHub 项目](https://github.com/littlhMW/rainward)** · **[下载游戏 Mod](https://littlhmw.github.io/rainward/downloads/WhereShouldIGo.zip)**

## 中文

- 地图默认遮住未探索房间的地形，同时保留房间与出口连接。导入游戏快照后，已访问房间会显示；玩家也可以逐房间调整遮罩，或显示完整地图。
- 普通地名正常显示。根据 Wiki 导航框中的分组，默认隐藏 17 个剧透区域名。地图图像、房间代码和主动展开的提示不受地名遮罩保护。
- 提供九位常规剧情角色的地图与逐层故事线索。线索用于指引方向，不会仅凭经过某个房间就判定剧情完成。
- 可选 Mod 默认长按 G 0.6 秒打开当前地点快照。雨甸中显示所有可获取的位置，探索进度只使用房主记录。客机收到的是房主周期起点快照，因此本周期的新探索可能延迟。
- 如果使用了新增或修改地形、房间或连接的 Mod，地图与提示可能不准确。本工具不会扫描已安装的 Mod。

## English

- The map masks terrain in unexplored rooms by default while keeping room and exit connections visible. Import a game snapshot to reveal visited rooms; rooms can also be shown or covered individually, or the full map can be revealed.
- Ordinary region names are visible. Seventeen region names grouped as spoilers in the Wiki navigation template are hidden by default. The name mask does not hide map artwork, room codes, or clues that you choose to reveal.
- Maps and layered story clues are available for the nine standard story campaigns. Clues suggest a direction; merely visiting a room never marks a story objective complete.
- The optional mod opens a snapshot of your current location when you hold G for 0.6 seconds by default. In Rain Meadow, it displays every player location it can read and uses only the host's exploration record. Clients receive the host's cycle-start snapshot, so exploration from the current cycle may appear later.
- Mods that add or change terrain, rooms, or connections can make the map and its guidance inaccurate. This project does not scan installed mods.
