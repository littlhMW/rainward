# 我该去哪儿 / Where Should I Go

直接基于 [Rain World Map](https://rain-world-map.github.io/) 开源前端调整的《雨世界》地图工具：真实地形与房间连接，附带逐层展开的故事线索。

**网站地址：[littlhmw.github.io/rainward](https://littlhmw.github.io/rainward/)** · **[源码仓库](https://github.com/littlhMW/rainward)**

- 黑白简洁界面；默认遮罩地形，开关即可显示完整原图。
- 普通地名可见，按 Wiki 明确分组隐藏 17 个剧透区域名。
- 九位常规剧情角色，同一界面使用原地图及 Watcher 真实地图数据。
- 故事线索、区域方向、实际房间出口连接参考、位置链接和本地备份。
- 可选“我该去哪儿”Mod：默认长按 G 打开当前地点，Remix 可改键；已编译，雨甸接口已核对，尚未实机单机/联机验收。
- GitHub Pages 免费托管，无需账户；地形和 JSON 按需联网读取。保留旧笔记，退役旧版离线缓存。

**[下载 Mod 安装包](https://littlhmw.github.io/rainward/downloads/WhereShouldIGo.zip)**。源码在 [rain-guide](rain-guide/)，参阅 [运行说明](rain-guide/README.md)、[Mod 安装](rain-guide/mod/README.md)、[来源与许可](rain-guide/upstream/UPSTREAM.md)、[验证记录](rain-guide/docs/QA.md)及[完整卸载](rain-guide/docs/UNINSTALL.md)。
