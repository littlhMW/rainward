# 雨间 · Rainward

给《雨世界》初来者的中文探索向导。默认遮罩详细地图，用匿名区域连接与三级提示推荐故事方向，把发现留给玩家。

**网站：[littlhmw.github.io/rainward](https://littlhmw.github.io/rainward/)**

- 九位常规剧情角色分别保存进度；Watcher 使用动态旅程路标。
- 原版 / Downpour 图谱、单向连接及已核实的剧情门槛。
- 18 条生存帮助、旅途笔记、备份导入导出、离线核心向导。
- 零运行依赖、无广告、无需账户，GitHub Pages 免费托管。

源码在 [rain-guide](rain-guide/)，参阅 [运行说明](rain-guide/README.md)、[来源与适用范围](rain-guide/docs/SOURCES.md)、[免费部署](rain-guide/docs/DEPLOY.md)及[卸载说明](rain-guide/docs/UNINSTALL.md)。详细外部地图和 Wiki 可能包含剧透。
