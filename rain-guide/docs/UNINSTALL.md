# 卸载、撤销配置与数据清理

雨间没有后台安装程序、全局 npm 依赖、数据库或常驻系统服务。项目文件可以整体移除；网页记录需在浏览器中单独清理。

## 下载和配置分别做什么

| 内容 | 意义 | 保存位置与清理方法 |
| --- | --- | --- |
| 项目 HTML、CSS、JavaScript 和数据 | 构成网页及防剧透提示 | 全部在 `rain-guide` 文件夹内；停止服务后删除该文件夹 |
| `package.json` | 提供便捷的预览与测试命令 | 在项目内；不包含第三方依赖，不需要 `npm install` |
| `scripts/serve.mjs` | 启动仅本机可访问的静态预览，检查路径避免目录穿越 | 按 `Ctrl+C` 停止；删除项目即可移除 |
| `scripts/check-browser.mjs` 与 `test-results/` | 使用已有 Playwright／Edge 做浏览器检查并保存检查产物 | 没有新增下载；删除 `test-results/` 即可清理产物，无需卸载其他项目使用的 Playwright 或 Edge |
| `localStorage` 中的 `rainward.progress.v1` | 保存九位角色的偏好、探索进度与笔记 | 存在浏览器个人资料中；使用「清除本站所有本地数据」移除 |
| `manifest.webmanifest` | 提供名称、图标和网页应用展示信息 | 位于项目内；不安装系统服务，也不自动建立离线缓存 |
| `sw.js` 与 `rainward-shell-v1` 缓存 | 缓存本站核心网页，使首次成功加载后可离线查看向导 | 服务范围限本站路径；「清除所有」会注销本站服务并删除名称以 `rainward-` 开头的缓存 |
| GitHub Pages 工作流 | 在推送后更新公开网页 | 位于发布仓库的 `.github/workflows/`；禁用或删除工作流 |
| GitHub 公开仓库与 Pages 设置 | 存储公开源码并托管网站 | 在 GitHub 管理；取消发布即可停止网站，删除仓库会同时移除源码历史 |
| 仓库级 Git 作者配置（若设置） | 为提交署名 `littlhMW` 与 `littlhMW@users.noreply.github.com` | 保存在该仓库 `.git/config`；删除独立仓库即可移除，不应改动全局 Git 配置 |

普通预览不下载任何 npm 依赖。若以后自己安装 Node.js，Node 是通用开发工具；它可能被其他项目使用，不需要为卸载本站而删除它。

## 仅停止本地预览

在运行 `npm run serve` 的终端按 `Ctrl+C`，再关闭页面即可。服务器监听 `127.0.0.1:4173`，没有注册为系统服务；重启电脑后也不会自动恢复。

## 清除攻略记录

如需保留记录，先在「关于雨间」选择「导出进度」。随后根据需要选择：

- **重置当前角色**：只重置当前角色的探索、线索、笔记和清单，保留其他角色。
- **清除本站所有本地数据**：确认后删除 `rainward.progress.v1`、本站离线缓存与本站 `sw.js` 服务注册，不修改游戏存档。当前页面仍可使用；清理后继续记录会重新产生进度，下次联网访问会重新注册离线服务并建立缓存。完整卸载时，清理后关闭本站所有标签页。

如果浏览器拒绝访问存储，页面会提示通过浏览器站点设置完成清理。也可以在开发者工具的 `Application／应用` 页面删除上述 localStorage 键和 `rainward-` 缓存，并注销脚本为本站 `sw.js` 的 Service Worker，避免影响其他网页。

- 本地预览的站点是 `http://127.0.0.1:4173`。
- 线上站点的域名以实际 GitHub Pages 地址为准。
- 同一个 `用户名.github.io` 域名下的其他项目可能共享站点存储；浏览器的「清除站点数据」可能影响同域其他网页。只想重置本站时优先使用页面自己的重置功能。
- 导出到「下载」文件夹的备份不会随站点数据一起删除；不再需要时手动删除。

如曾通过浏览器将网页安装为应用，在浏览器的应用管理中卸载「雨间」；固定到桌面或开始菜单的快捷方式也可单独移除。

## 完整移除本地项目

1. 在网页「关于雨间」导出需保留的记录，再执行「清除本站所有本地数据」，关闭本站所有标签页。
2. 停止预览服务，并备份仍需保留的项目文件。
3. 在资源管理器确认正在操作的是本项目文件夹，例如 `<你的项目目录>\rain-guide`，然后删除该文件夹。不要误删父目录或共享仓库。
4. 根据需要清理浏览器中对应站点的数据。

若项目位于已有仓库的子目录，父仓库 `.git` 与其他文件不属于本项目，不应一并删除。移到仓库根目录的 Pages 工作流也需单独禁用或移除；若该工作流后来兼用于其他站点，只移除本站相关步骤。

## 停止公开访问

先取消 Pages 发布，再禁用自动部署工作流。操作细节见 [免费发布说明](DEPLOY.md#撤销发布)。停止公开访问不会删除访问者自己浏览器中保存的进度；访问者需要自行清除本地记录。
