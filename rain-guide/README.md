# 雨间 · Rainward

一个面向《Rain World／雨世界》新手的中文探索指南。默认从「幸存者、尚未探索」开始，用区域连接关系帮助决定下一步；详细地图通过遮罩开关按需查看，剧情信息逐层揭示。

项目参考 [Rain World Interactive Map](https://rain-world-map.github.io/) 的地图导航方式，并使用官方社区 Wiki 等公开资料核对信息。这是独立的非官方指南，与游戏开发者及原地图维护者没有隶属关系。

支持九位常规剧情角色：原版三位、Downpour 五位和 Watcher 一位。每位角色有独立进度、剧情路标和生存提醒；Watcher 的传送关系随进度变化，因此只显示剧情路标，不编造固定连接。秘密额外模式与竞技场角色不纳入常规剧情路线。

界面、中文分级提示和连接示意为原创实现，没有第三方运行依赖，不重新分发游戏文件、音乐或原站地图图片。基础三位可在左栏「版本设置」中选择原版或 Downpour 图谱；扩展区域与特殊条件请查看所选角色的「地图适用范围」。

## 使用方式

1. 选择正在游玩的角色，并标记自己已经到过的区域。
2. 保持默认遮罩，只查看连接与不含剧情细节的方向建议。
3. 卡住时逐步打开更明确的提示；只有准备好接受额外信息时才打开详细地图或原始资料。
4. 在生存手册查看操作、生存与卡关建议，用出门清单和旅途笔记记录自己的发现。
5. 在「关于雨间」导出或导入所有角色的进度备份。不同角色的区域与通路可能不同，不应将某一角色的路线直接套用到其他角色。

外部完整地图和 Wiki 可能直接展示区域名称、角色经历和结局。站内遮罩无法遮罩外部网页。

初次游玩时，让版本设置与游戏实际启用的 DLC 保持一致。跨角色可选路线默认关闭，只有展开「我已通关过其他角色：设置可选路线」后才会看到条件：同存档槽已完成饕餮的玩家，可手动为幸存者／僧侣启用已解锁的路线。本站不读取游戏存档，无法自动确认这一条件。

## 本地运行

需要现有的 Node.js 18 或更新版本，无第三方运行依赖，**无需运行 `npm install`**。

在此文件所在目录打开终端，运行：

```powershell
npm run serve
```

然后打开 <http://127.0.0.1:4173/>。按 `Ctrl+C` 停止预览。直接双击 HTML 文件可能受浏览器对 ES modules 的限制，请使用上述预览服务。

服务只监听本机，不会在局域网或互联网提供访问。它不安装服务、不创建自启动项，也不修改系统设置。

运行自动检查：

```powershell
npm test
```

GitHub Pages 工作流会使用 Node.js 20 先执行同一组检查，再发布静态页面。

`npm test` 使用跨平台的 `node --test`。2026-10-12 的本地验证已通过 43 项 Node 测试和 33 项浏览器检查。浏览器检查脚本为 `scripts/check-browser.mjs`，本次使用电脑上已有的 Playwright 与 Edge，没有下载浏览器或增加项目依赖。

需要复跑浏览器检查时，先启动本地预览，再让 `PLAYWRIGHT_MODULE` 指向已有的 Playwright 包、`BROWSER_PATH` 指向已有的 Edge／Chrome 可执行文件，运行：

```powershell
node scripts/check-browser.mjs
```

脚本默认检查 `http://127.0.0.1:4173/`，可通过 `SITE_URL` 改为其他地址。截图等检查产物保存在 `test-results/`，已被 Git 忽略；删除该目录即可清理。浏览器检查不包含在 Pages 自动发布流程内。

## 隐私与清理

进度与笔记仅保存在浏览器的 `localStorage` 键 `rainward.progress.v1` 中，不需要注册游戏指南账号。不同浏览器和设备的记录互不相通；同域名的网页共享浏览器存储空间。清除前可在「关于雨间」导出备份。

首次成功加载并建立缓存后，核心向导可离线使用。本站的 `sw.js` 只在本站路径范围内提供离线服务，缓存名称为 `rainward-shell-v1`；外部地图和 Wiki 仍需要联网。「清除本站所有本地数据」会移除进度、笔记、本站离线缓存与服务注册。再次联网访问会重新建立缓存。

下载文件、配置的用途，以及停止预览、取消发布、移除数据的方法，见 [卸载与数据清理](docs/UNINSTALL.md)。

## 维护与资料

- 原始资料可能涉及剧透。项目内的推荐文字应保持低剧透，准确路线与版本差异应另行核对。
- 游戏版本、DLC 和角色会影响地图；不确定的内容应明确标记，不能用普通幸存者地图冒充所有角色的准确地图。
- 更新角色或路线数据后，先运行已有测试，再检查首次打开状态、遮罩开关和小屏幕显示。
